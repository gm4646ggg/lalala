🎓 Дипломный проект: «Автоматизация школьной библиотеки»

Информационная система для учёта книг, читателей, выдачи и возврата.

📌 Задачи системы

  • ✔ Управление читателями (поиск, добавление, класс, телефон)
  • ✔ Каталог книг с фильтрацией по жанру, автору, статусу
  • ✔ Оформление выдачи и возврата с контролем сроков
  • ✔ Формирование списка должников и аналитика популярных книг
  • ✔ Авторизация библиотекаря

⚙ Технологический стек

Python / Django PostgreSQL HTML5/CSS3 JavaScript (ES6) Bootstrap 5

Трёхуровневая архитектура, адаптивный интерфейс, триггеры для просрочек.

📊 Результаты внедрения

  • 📈 Сокращение времени на поиск книг на 60%
  • 📋 Автоматические отчёты о должниках
  • 🌟 Топ самых популярных книг
  • 🖥 Удобный интерфейс для библиотекаря
📸 Интерфейс системы (7 ключевых экранов)
Рис. 1 — Авторизация
Страница входа для сотрудников
Рис. 2 — Журнал выдач
Активные выдачи с датами
Рис. 3 — Читатели
Поиск, класс, телефон, дата рождения
Рис. 4 — Каталог книг
Название, автор, жанр, статус
Рис. 5 — Выдача/возврат
Выбор читателя и книги
Рис. 6 — Должники
Автоматический отчёт с телефонами
Рис. 7 — Топ книг
Статистика выдач
