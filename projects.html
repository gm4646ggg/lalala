🎓 Дипломный проект
«Автоматизация деятельности школьной библиотеки»
Разработка информационной системы для учета книг, читателей, выдачи и возврата литературы.
Проект включает веб-интерфейс, базу данных и аналитику популярных книг.

📌 Цель и задачи

Создать удобную автоматизированную систему для школьной библиотеки, позволяющую:

  • ✔ Управлять читателями (добавление, редактирование, поиск).
  • ✔ Вести каталог книг с фильтрацией по жанру, автору, статусу.
  • ✔ Оформлять выдачу и возврат книг с контролем сроков.
  • ✔ Формировать список должников и аналитику популярных книг.
  • ✔ Обеспечить авторизацию сотрудников.

⚙ Технологический стек

Python / Django PostgreSQL HTML5 / CSS3 JavaScript (чистый) Bootstrap 5 Django ORM

Интегрированная отчетность, адаптивный дизайн, безопасная аутентификация. БД содержит таблицы: читатели, книги, выдача, жанры, классы. Реализованы триггеры для контроля долгов.

📊 Результаты внедрения

  • 📈 Сокращение времени на поиск и выдачу книг на 60%.
  • 📋 Автоматическое формирование отчетов о должниках.
  • 🌟 Выявление самых востребованных книг (аналитика выдач).
  • 🖥 Удобный интерфейс для библиотекаря и администратора.
